# راهنمای آموزشی دارو و مکمل — دارووی

مواد این پوشه برای انتشار به‌صورت **GitHub Pages** آماده شده‌اند. هنوز در GitHub بارگذاری یا منتشر نشده‌اند.

آدرس پیش‌فرض (canonical و sitemap هم همین را فرض کرده‌اند):

`https://darooway.github.io/`

اگر نام کاربر یا سازمان GitHub چیز دیگری باشد، قبل از انتشار این رشته را در `sitemap.xml`، `robots.txt` و تگ `rel="canonical"` همهٔ صفحه‌ها عوض کنید.

## محتوا

| پرونده | موضوع |
|---|---|
| `index.html` | صفحهٔ اصلی راهنما |
| `labels-its.html` | برچسب جعبه، کاردکد (Data Matrix) و استعلام در سامانهٔ رسمی İTS ترکیه |
| `storage-expiry.html` | نگهداری و تاریخ انقضا، بر پایهٔ FDA |
| `guides.html` | فهرست راهنماهای دارویی بر اساس گروه درمانی، با پیوند به مقاله‌های بلاگر، وردپرس، نیلوبلاگ و مدیوم |
| `drugs.html` | خلاصهٔ آموزشی چند دارو (بدون مقدار مصرف) با پیوند به صفحه‌های موضوعی موجود در darooway.com |
| `styles.css` | شیوهٔ ظاهری مشترک |
| `sitemap.xml` | نقشهٔ سایت |
| `robots.txt` | اجازهٔ خزیدن |

نویسنده در همهٔ صفحات: **تیم محتوای دارووی (DarooWay Content Team)**. مطالب از نظر پزشکی بازبینی بالینی نشده‌اند و جایگزین مشورت با پزشک یا داروساز نیستند.

## انتشار (بعد از تأیید؛ در این مرحله انجام نشده)

1. در GitHub یک مخزن عمومی بسازید؛ برای آدرس بالا نام مخزن باید `darooway.github.io` و زیر کاربر یا سازمان `darooway` باشد.
2. محتویات همین پوشه را در شاخهٔ پیش‌فرض، در ریشهٔ مخزن بگذارید.
3. در Settings → Pages منبع را همان شاخه (root) انتخاب کنید.
4. پس از زنده شدن سایت، آدرس‌ها را می‌توان در Bing Webmaster Tools ثبت کرد. در صورت تمایل، کلید IndexNow را هم در ریشهٔ همین میزبان بگذارید.
